# 生活费记账
这是AI agent制作，人工调试的项目。提示词在`prompt.md`下。

## 项目简介
这是一款基于 Auto.js Pro 开发的自动化辅助脚本。旨在帮助用户在移动端快速记录日常开销，通过自动化技术简化记账流程，提高个人财务管理效率。

## 功能介绍
*   **双模块资金管理**：将每月生活费划分为“校园卡”和“活动资金”两大模块，方便用户分类管理不同用途的资金。
*   **流水记录**：支持为两个资金模块分别记录收入和支出，可自定义分类和添加备注。
*   **余额修正**：提供余额修正功能，当实际余额与记录不符时，可一键调整，确保账目准确。
*   **月末结转**：支持月末结转功能，可将“活动资金”的结余自动转入“存款贡献”模块，并清零“活动资金”余额。
*   **存款贡献统计**：自动统计历史所有月份的“存款贡献”总额，清晰展示累计储蓄情况。
*   **数据导入导出**：支持将账本数据导出为 JSON 文件或 CSV 报表，也支持从 JSON 文件导入数据，方便备份和迁移。
*   **图表分析**：提供饼图功能，直观展示指定月份或全部时间内的支出分类占比。

## 环境要求
- **运行平台**：Android
- **运行环境**：Auto.js Pro (必须为 Pro 版本，开源版可能不兼容)
- **权限要求**：无障碍服务、悬浮窗权限、存储权限

## 安装与构建
本项目采用直接导入源码的方式运行，无需复杂的编译或构建过程。

1. **获取源码**
   下载本项目中的 `LivingExpenseManager.js` 文件。

2. **导入脚本**
   将下载好的 `LivingExpenseManager.js` 文件复制或移动到手机的 Auto.js Pro 脚本目录中。

3. **加载项目**
   打开 Auto.js Pro 应用，在脚本列表中即可看到该脚本。

## 使用说明
1. **启动脚本**
   在 Auto.js Pro 中点击 `LivingExpenseManager.js` 右侧的运行按钮。

2. **权限配置**
   首次运行时，系统会提示开启“悬浮窗权限”，因为所有弹窗提示都是悬浮窗。
